Home Affairs Assistant App

Citizen services, in one place.

A student demonstration of a mobile experience for exploring Home Affairs services, applications, and appointments.

Download the Android app Check demo service status

Install on Android

Download the APK on an Android phone, open it, and allow installation when Android asks. The demo requires Android 6.0 or newer.

Present from a PC

  1. Open the project in Android Studio.
  2. Start a virtual device from Device Manager.
  3. Run the app on that device, or drag the downloaded APK into the emulator.

About this demo

This is an independent student prototype, not an official Department of Home Affairs service. Use fictional details for demonstrations.

The Android APK runs on Android devices or in an Android emulator. It does not run directly as a Windows application in a web browser.
